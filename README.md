⚡ VIDYUTRENZ Symposium Website

Official symposium website developed WEB DEVELOPMENT HEAD for the ECE Department Symposium VIDYUTRENZ at Chennai Institute of Technology.

🌐 Live Website: https://vidyutrenz-26.vercel.app/

📌 Overview

VIDYUTRENZ is a production-level symposium website built to centralize and manage all event-related information including technical events, non-technical events, workshops, schedules, rules, and registration access.

The platform was designed for reliability, responsiveness, and smooth participant experience during live symposium operations.

👨‍💻 My Contribution

As Web Development Head, I individually handled the core development of the symposium website.

My responsibilities included:

Designing the complete UI structure and layout

Architecting modular React component structure

Developing all primary pages (Home, Events, Workshops, About, Contact)

Implementing event cards with timing, rules, and prize details

Integrating PDF-based event documentation

Connecting Google Forms registration workflows

Managing live updates and feature enhancements during the event

Maintaining version control using Git & GitHub

This project reflects end-to-end frontend ownership in a real academic event environment.
